# موقع أصول للحلول المالية — نسخة مستقلة (بدون Replit)

هاد نفس موقعك بالضبط، لكن كود نضيف يشتغل بأي مكان — ما إله أي علاقة بـ Replit.

## 1) شغّله على جهازك (اختياري، بس للمعاينة)

يلزمك تحميل Node.js (من nodejs.org) مرة وحدة، وبعدين:

```
npm install
npm run dev
```

بيفتح على http://localhost:5173

## 2) الطريقة الأسهل والمجانية للنشر: Netlify

1. روح لموقع https://app.netlify.com وسوّي حساب مجاني (بالإيميل مباشرة، بدون بطاقة).
2. اسحب مجلد المشروع كامل (هاد الفولدر) وفلّتو داخل صفحة Netlify (فيه مكان مكتوب عليه "Drag and drop").
   - **بس لازم أول شي تعمل build محلي أو تخلي Netlify تعمله**. الأسهل: اربط حساب GitHub بدل السحب المباشر:
3. ارفع هاد المجلد على GitHub (مستودع جديد فاضي، وارفعله الملفات).
4. من Netlify: "Add new site" → "Import an existing project" → اختار المستودع.
5. بالإعدادات:
   - Build command: `npm run build`
   - Publish directory: `dist`
6. اضغط Deploy — وبعد دقيقة أو دقيقتين رح يطلعلك رابط مجاني زي `osool.netlify.app` وموقعك شغال عليه بدون ولا قرش.

(نفس الطريقة بالضبط تنفع مع Vercel أو Cloudflare Pages لو حبيت، الخطوات مطابقة تقريبًا.)

## 3) ربط الدومين اللي شريته من Hostinger — مجانًا

أنت مش مضطر تدفع لـ Hostinger مصاري استضافة، فقط استخدم الدومين وخليه يشاور على Netlify:

1. من لوحة تحكم Hostinger، روح لإدارة الدومين (Domain) — مش الاستضافة (Hosting).
2. دور على "DNS / Nameservers".
3. من إعدادات Netlify: Site settings → Domain management → Add custom domain → حط الدومين تبعك.
4. Netlify رح يعطيك إما:
   - سجلات DNS (A record + CNAME) تحطها بلوحة Hostinger تحت "DNS Zone"، أو
   - Nameservers جديدة تستبدل فيها nameservers الدومين بلوحة Hostinger.
5. بعد التحديث (بياخد من دقايق لساعات لين ينتشر)، الدومين رح يفتح موقعك مباشرة من Netlify مجانًا، وحتى SSL (https) بينضبط تلقائي.

## ملاحظات

- هاد الموقع صفحة تعريفية (Landing Page) بس — ما فيه قاعدة بيانات ولا سيرفر خلفي، فما رح تحتاج تدفع اشتراك استضافة أبدًا لتشغيله.
- زر الواتساب العائم والنموذج شغالين بشكل ثابت بالواجهة فقط.
